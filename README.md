# KARMASH — сайт-портфолио

Три страницы: главная (`/`), дизайн (`/design/`) и арт (`/art/`). Сайт сделан на чистом HTML, CSS и JavaScript. Ничего устанавливать и собирать не нужно.

## Как посмотреть сайт у себя

Нужен только [Node.js](https://nodejs.org).

```
node server.js
```

Потом откройте http://localhost:5173.

Просто открыть `index.html` двойным щелчком не получится: браузер не загрузит модули и не поймёт адреса вида `/design/logopotam`.

## Как выложить на Vercel

Залейте папку в репозиторий GitHub (например, в `KARIVA`) и подключите его в Vercel. Настройки сборки не нужны. Файл `vercel.json` уже настроен так, чтобы ссылки на кейсы (`/design/logopotam`) открывались напрямую и после обновления страницы.

На другом хостинге прямые ссылки тоже работают: их перехватывает `404.html`.

Если домен не `kariva.vercel.app`, замените его в `index.html`, `design/index.html`, `art/index.html`, `sitemap.xml` и `robots.txt`.

## Где что лежит

```
index.html            главная
design/index.html     страница DESIGN
art/index.html        страница ART
src/
  data/               ← ВЕСЬ КОНТЕНТ. Править в первую очередь здесь
    site.js           тексты, навигация, контакты, подписи, пустые места под ваши тексты
    career.js         карьерный путь (ветка)
    skills.js         навыки (лента) и программы с уровнями 0–10
    designProjects.js кейсы DESIGN
    artProjects.js    работы ART (6 пустых ячеек)
    collage.js        расположение кусочков коллажа на главном экране
    decor.js          маленькие рисованные знаки на полях
  components/         части сайта (коллаж, ветка, окно кейса, подвал…)
  pages/              скрипты страниц: собирают всё вместе
  styles/             tokens.css — цвета и шрифты бренда; base.css, home.css, pages.css
  assets/             картинки, шрифты, логотип
```

## Частые задачи

- **Вписать текст на главной.** Откройте `src/data/site.js` и заполните `heroText` (полоса под именем) и `introText` (фраза на бумажке в коллаже). Всё, что пока пусто, видно на сайте как карандашная пометка «✎ …». Когда заполните, поставьте `showPlaceholders: false`.
- **Добавить место работы.** В `src/data/career.js` скопируйте последний блок `{ … },` и поменяйте текст. Ветка перестроится сама.
- **Добавить работу в ART.** Инструкция в начале `src/data/artProjects.js`. Коротко: картинку положите в `src/assets/art/`, путь впишите в `image`, для новой работы скопируйте блок и задайте новый `slug`.
- **Добавить кейс в DESIGN.** Инструкция в начале `src/data/designProjects.js`. Картинки кейса лежат в `src/assets/projects/<slug>/`. Не забудьте добавить строку в `sitemap.xml`.
- **Обложки больших листов ART / DESIGN на главной.** В `site.js` → `albums.art.image` и `albums.design.image`. Пока там пусто, показывается коллаж.
- **Поменять фото в «Обо мне».** `site.js` → `about.photo`.
- **Описание для поисковиков.** Тег `<meta name="description">` в каждом из трёх HTML-файлов.

## Как добавить новый кейс в DESIGN (с фильтрацией)

**1. Подготовьте картинки** (формат WebP, имена строго такие):

| Файл | Размер | Для чего |
|---|---|---|
| `cover-900.webp` | 900 × 1250 px (пропорция 18:25) | обложка карточки, крупная |
| `cover-520.webp` | 520 × 722 px | та же обложка, лёгкая версия |
| `slide-01-1800.webp`, `slide-02-1800.webp`… | ширина 1800 px | слайды в окне кейса (компьютер) |
| `slide-01-1100.webp`, `slide-02-1100.webp`… | ширина 1100 px | те же слайды, лёгкая версия |
| `mobile-01.webp`, `mobile-02.webp`… | ширина 900 px | слайды для телефона (необязательно) |

Нумерация всегда с двумя цифрами: `01`, `02`… `10`. Если версию для телефона не делаете, поставьте в кейсе `mobileSlides: 0`, тогда телефон возьмёт слайды для компьютера.

**2. Создайте папку:** `src/assets/projects/<slug>/` и положите туда все файлы. `<slug>` — короткое имя кейса латиницей, цифры и дефис: `bakery-brand`, `cafe-menu-2`.

**3. Добавьте кейс в `src/data/designProjects.js`.** Скопируйте любой блок `{ … },`, вставьте в конец списка (перед `];`) и поменяйте значения:

```js
{
  slug: 'bakery-brand',                       // как папка в assets/projects
  title: 'Фирменный стиль пекарни',           // заголовок
  short: 'Логотип, упаковка, меню',           // подпись под карточкой
  year: '',
  skills: ['Фирменный стиль', 'Дизайн полиграфии'],   // ← ПО НИМ РАБОТАЕТ ФИЛЬТР
  tools: ['Illustrator', 'Photoshop'],        // программы (бирки)
  description: 'Текст о проекте…',
  task: '', work: '', result: '',
  cover: 'cover',                             // не меняйте, если файлы названы cover-900 / cover-520
  slides: 5,                                  // сколько слайдов slide-XX для компьютера
  mobileSlides: 5,                            // сколько файлов mobile-XX (0 — нет)
  imageSizes: [1800, 1100],                   // какие ширины сохранили
},
```

**4. Фильтрация работает сама.** Кнопки фильтров строятся автоматически из поля `skills` всех кейсов:

- Хотите, чтобы кейс попадал в фильтр «Фирменный стиль» — впишите это слово в `skills`. Написание должно совпадать **буква в букву** (регистр, точки, пробелы), иначе получится отдельная кнопка.
- Хотите **новый фильтр** — впишите в `skills` нового кейса новое название (например `'Иллюстрация'`). Кнопка появится сама. Фильтр с одним кейсом тоже будет, так что лишние названия лучше не придумывать.
- Один кейс может быть в нескольких фильтрах: перечислите навыки через запятую.
- Порядок кнопок — по порядку первого появления навыка в списке кейсов. Кнопка «Все» всегда первая.
- Если у нового кейса нет `skills`, он виден только в «Все».

**5. Бирки программ.** Программы из `tools` рисуются бумажными бирками, если есть картинка в `src/assets/tags/` и запись в `src/data/skills.js` → `toolTags`. Для остальных (например, Krita, Grok) нарисуется простая бумажка с названием. Не нужна бирка — просто не указывайте программу в `tools`.

**6. Порядок карточек** на странице такой же, как порядок кейсов в файле. Новый кейс в конце списка окажется последним; хотите первым — вставьте блок в начало списка.

**7. Проверьте и выложите.** Запустите `node server.js`, откройте http://localhost:5173/design/, нажмите на новый кейс и на фильтры. Затем добавьте строку в `sitemap.xml`:

```
<url><loc>https://kariva.vercel.app/design/bakery-brand</loc></url>
```

Закоммитьте всё в GitHub, Vercel обновит сайт сам.

## Картинки

Используйте формат WebP. Обложки кейсов сохраняйте шириной 900 и 520 px, слайды — 1800 и 1100 px. Если сохраняете только одну ширину, укажите это в кейсе: `imageSizes: [1800]`. Картинки ниже первого экрана грузятся, только когда до них доходит прокрутка. В окне кейса загружается только текущий слайд и соседние.

## Что откуда взято

- **Цвета, шрифты, коллаж, ива, бирки, символы, логотип** — из дизайн-системы Karmash.
